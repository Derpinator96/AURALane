# The hosted API: python -m core.run serve, AURALANE_RUNTIME=aws (auralane-api)
# or fixture (auralane-preview). Only what serve imports. No torch, no monai,
# no transformers: the deployed API never runs a model (see docs/DEPLOY.md).
# Verified by installing exactly this file into an empty Python 3.14 venv over
# a copy of the committed tree, starting the API and calling every route.
#
# Why each one is here:
#   fastapi, pydantic   core/api.py
#   uvicorn             core/run.py serve
#   PyJWT               core/providers/local/devauth.py (fixture sign-in)
#   numpy, nibabel      adapters/brats.py, imported by core/registry.py
#   boto3               core/providers/local/dynamo.py, imported by the local
#                       package the fixture runtime reuses (never called)
#   httpx, pydicom      core/providers/local/orthanc.py, same reason
#   cryptography        aws runtime: Cognito tokens are RS256 (PyJWT needs it)
#   pylibjpeg-openjpeg  aws runtime: decodes HealthImaging's HTJ2K frames for
#                       the API's frame stream (AURALANE_FRAME_MODE=proxy)
#   pillow, scipy       simulated ingest (core/simulate.py): the API orchestrates
#                       the pipeline, which imports sim/edge/deid.py (Pillow),
#                       renders the brain overlay (Pillow) and runs the brain
#                       mask check (scipy). No model: those run on Lambda and
#                       SageMaker. No pytesseract: staged studies arrive already
#                       de-identified and are checked, not OCRed again.
#
# Not here: python-multipart. No route takes form data (no Form or UploadFile
# in core/api.py).
